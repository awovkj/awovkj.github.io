无限大小tg图床项目魔改

Created2026-03-19Updated2026-03-19

相对于原项目的改进

  1. 支持 CF Workers 搭建，更加方便 Cloudflare 优选
  2. 使用 Durable Objects，大幅减少大文件上传报错
  3. 新增音乐/视频播放器功能(在其他设置中启用)，可用于搭建自己的音乐库或视频库

搭建方法（CF Workers）

📦本项目地址：https://github.com/awovkj/CloudFlare-ImgBed原项目地址：https://github.com/MarSeventh/CloudFlare-ImgBed 

其他搭建方法与原项目一致，详见 官方文档

  1. Fork 本项目到你的 GitHub 账号
  2. 在 Cloudflare 中连接该仓库
  3. 将部署命令设置为 npm run worker:deploy
  4. 直接部署即可（KV 等资源会自动创建并绑定）
