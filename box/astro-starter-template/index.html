资源详情

资源介绍

Astro 官方提供了多种可直接初始化的网站模板，适合快速搭建博客、文档站、作品集和营销页面。模板使用静态站点生成方式，部署后无需单独运行应用服务器。

模板特点

  • 提供博客、文档、作品集等多种起步示例。
  • 支持 Markdown、MDX 与内容集合。
  • 可以使用 Astro、React、Vue、Svelte 等组件。
  • 能部署到 GitHub Pages、Cloudflare Pages、Netlify 等静态托管平台。

快速使用

在终端执行以下命令，按提示选择模板：

npm create astro@latest
cd my-astro-site
npm install
npm run dev

开发服务启动后，终端会显示本地访问地址。构建生产版本时执行：

npm run build

生成的静态文件位于 dist/ 目录。
